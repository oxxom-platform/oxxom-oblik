# Запис на персональне демо

Реалізовано тестовий прототип відповідно до уточнення власника:
юридична особа й політика готуються, тільки синтетичні контактні дані.
Поточна реалізація, перевірки й межі: [DEMO-BOOKING-01.md](DEMO-BOOKING-01.md).

Після перевірки встановлення на Ubuntu залишається окремий майбутній перехід
до робочого приймання контактів: реквізити, політика, правова підстава, retention
та перевірена корпоративна доставка. Режим цього випуску fixture-only.
