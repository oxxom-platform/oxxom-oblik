# LANDING-03 — скруглена основа ноутбука та м’який фон

16.11.2026. За візуальним уточненням власника перероблено нижню частину
ноутбука та прибрано жорстку діагональну межу м’ятного тла.

Основа — окремий SVG-компонент `core/laptop-base.html`: скруглений металевий
контур, тонкий передній торець, 65 індивідуальних клавіш, заглиблений трекпад,
виїмка передньої кромки та спільний із кришкою шарнір. Замість повторюваної
сітки й гострого polygon-вирізу використані власні векторні контури.
Висота й ширина основи підлаштовуються під наявну композицію пристроїв.

Тло hero замінене на нерухомі радіальні градієнти з прозорими краями.
Вони утворюють ефект розсіяного м’ятного світла без прямого скошеного зрізу
та без анімованого blur-фільтра.

Перевірено у Chrome на 360, 390, 768, 1440 і 1920 px: немає горизонтального
переповнення, основа цілком у межах вікна, маски дисплеїв активні. Desktop
і mobile оглянуті візуально; SVG коректний, помилок JavaScript немає.
Це візуальна правка; нові тести або зміни бази даних не потрібні.

Після оновлення перезапустити `sh scripts/start-core.sh` і відкрити
http://127.0.0.1:4180/. Змінено параметр версії CSS, щоб оновився кеш.
