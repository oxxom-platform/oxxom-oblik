# Поточний стан OXXOM OBLIK

Оновлено 17.11.2026. Поточний застосунок — Django/PostgreSQL у `backend/`.
Публічна адреса: https://oblik.oxxom.com.ua/.

Цей документ узагальнює стан продукту. ТЗ й протоколи окремих етапів зберігають
відомості на момент їх написання й можуть містити історичні незавершені пункти.

## Реалізовано в коді

- Організації, членство, п’ять ролей, серверні перевірки доступу та керування працівниками.
- Вхід із паролем і TOTP, QR-підключення, одноразові резервні коди; MFA-сесія до семи днів.
- Довідники, багаторядкові документи, складські та грошові операції.
- Проведення й сторно, облікові рухи, залишки та середньозважена собівартість.
- Внутрішній облік оплат, звіти й CSV, друк документів та імпорт довідників.
- Спільний робочий простір, мобільне меню, чотири мови інтерфейсу.
- Чотири серверні мовні головні сторінки, canonical/hreflang, метадані,
  sitemap/robots, noindex приватних відповідей і спільний favicon OBLIK.
- [DEMO-01](DEMO-BOOKING-01.md): чотири мовні сторінки запису, CTA, footer email,
  fixture-only заявки й тестовий outbox. До політики та реквізитів реальні контакти
  не приймаються; робочий режим і фактична SMTP-доставка не активовані.

## Підтвердження власника на встановленій системі

| Перевірка | Підтверджений результат |
|---|---|
| Перенесення | Ubuntu-backend запущено, дані та чинний MFA-доступ перенесено |
| Публічний доступ | Власник відкрив сайт через HTTPS-домен |
| Резервна копія | `FIRST BACKUP OK`: зашифровані сховища перевірені, відновлені файли звірені SHA256 |
| Ізольоване відновлення | `RESTORE TEST OK`: міграції, суми, залишки та ключі MFA перевірені; тимчасові БД/роль видалені |
| SEO-01 | `SEO-01 OK`; збережені попередні файли, пройдені внутрішні перевірки після установки |
| SECURITY-01A | Власник отримав `SECURITY-01A OK`; підтверджені flags ролі БД, sandbox сервісу, Secure/HttpOnly і сім днів сесії |
| Сторінки помилок | Власник перевірив 404; файли для зовнішнього NPM передано, окрема й загальна конфігурації пройшли nginx -t; кінцевий browser smoke після підключення include ще не підтверджений |
| Search Console | Домен додано, sitemap подано; у звіті URL видно виявлення головної через sitemap |
| Перевірка Google | Власник отримав «URL доступен Google» і підтвердив перевірки мовних сторінок та запити на індексування |

Установлений SEO-реліз: коміт
[`3d66823`](https://github.com/oxxom-platform/oxxom-oblik/commit/3d6682373249f55b229ea75955d98b0af2a5cbef).
Це ідентифікатор конкретного оновлення, а не твердження про повну тотожність
усіх операційних файлів VM і цього коміту.

Перевірки зовнішнього HTTPS із середовища асистента та зі шляху доступу Ubuntu
завершувалися таймаутами. Їх не зараховано як успішні. Окремо зафіксовані
успішний браузерний доступ власника, live-перевірка Google і відповідь
`200 OK` від backend за запитом із reverse proxy.

## Що ще не прийнято як завершене

| Напрям | Залишилося |
|---|---|
| Favicon | [FAVICON-02](FAVICON-02.md): дефект маленьких ICO-кадрів виправлено в коді; застосування патча на Ubuntu та вигляд вкладки потребують підтвердження |
| Бекапи | Постійне монтування, розклад, retention, повідомлення про збої та перевірка після reboot |
| Експлуатація | Повний сценарій після перезавантаження, періодичне відновлення, вимір RPO/RTO |
| Пілот | Бухгалтерське приймання, навантажувальні сценарії та комерційні умови |
| Пошук | Фактичне індексування та покази, зовнішні перевірки всіх SEO-сигналів |
| Швидкодія | Лабораторні заміри Lighthouse і польові Core Web Vitals |
| Розвиток SEO | Тематичні сторінки, семантика та аналітика наступних SEO-етапів |
| Інтеграції | ПРРО, банки, M.E.Doc, документований зовнішній API та інші погоджені підключення |

Публічний доступ до MVP і можливість сканування Google не замінюють
бухгалтерського, навантажувального або експлуатаційного приймання.
